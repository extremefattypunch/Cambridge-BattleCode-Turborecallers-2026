**Champion:** `results/CHAMPION` (c2_respawn, website v4). Lineage: tb_merge_b (v2) → q24_combo (v3) → c2_respawn (v4, live). The full text of this file before the 1 Nov restructure is in `results/strategies-archive.md`. Note paths below are relative to the bot folder.

**Rule (user, 31 Oct):** every simulated match tests a **new, meaningful, distinct strategy** with improvement potential, drawn from real ladder games, our own bots or postmortems. No simulation for its own sake. Submissions = the strongest bot found.

**Keeping this file bounded (LOOP.md step 3):**
- Each verdict is one row in `## Tested`, and each open hypothesis is one row in the single ranked `## Queue`. Both link the note.
- Never add a "New hypotheses from …" section.
- Past ~300 lines, move the closed Tested rows from before the champion's lineage to `results/strategies-archive.md`.

**Test protocol:**
1. **Pre-register.** `tools/new_sim_note.py <cand> --vs <champion> --prev <parent>` creates the note. Fill in §1 and §2 (hypothesis, evidence links, numeric prediction) before anything runs.
2. **Implement** the strategy in its own candidate bot (`tools/newbot.py <champion> <cand>`; never edit the champion).
3. **Screen** with `tools/eval.py <cand> <champion> --maps quick`. Where relevant, also play imitation opponents of the real ladder comps that beat us. A screen of ≥ 55% goes straight to the LOOP.md §4 promotion gate.
4. **Analyse and record.** Run the analysis session and finish the note. Record the verdict (kept / rejected / inconclusive / promoted) as one Tested row, and merge the new hypotheses into the Queue. **Never re-test a rejected idea unchanged.**

**Methodology notes:**
- **Determinism and side bias.**
  - Local games are deterministic: the same bots on the same map give byte-identical results. Never re-run a map; cover more maps instead (`--maps all` = 140 games).
  - A 40-game sprint eval has about ±8% map-sampling noise.
  - In a mirror, team B wins 15/20 sprint maps, so always play both sides.
- **Placebo noise floor (T28).**
  - Null changes score 66 and 68/140, against the mirror's 70.
  - Trajectory SD is ≈ 5.0 per re-rolled 140-game run, below the binomial 5.92. So the ≥ 82/140 gate stands: about 1% false passes, or about 3% after a sprint screen. Gate (f)'s placebo replicate closes that gap.
  - h_antistun's estimate of 70 ± 6.6/140 (± 3.2/40 on sprint) means a ≥ 55% sprint screen passes about 30% of no-op changes. A single run cannot attribute a ~5-game difference.
- **Scoped fixes (H-C, batch 5).**
  - Fixes keyed on team size, a rare trigger or no_tribute leave most games unchanged, so they cannot reach 82/140 head-to-head.
  - Bundle them into combos gated at the full bar (V1). Changing the gate itself is the user's call.
- **Blind spot (1 Nov).**
  - Every local opponent (sf_*, tb_*, imit_*, lad_*, h3_*) runs our own farming and safety logic. So maps where *our logic* scores 0 look like 0-0 ties locally, while real opponents score 1,000 there (Q26, Q27).
  - Judge map-structure fixes by our own clears and tributes, not only by the local result.
